# Delivery and Implementation

The project is intentionally backend-first for implementation because KMP clients are generated from the backend-produced OpenAPI documents.

Order:
1. Foundation documents.
2. Backend technical POCs.
3. Backend implementation.
4. Generate/review/commit OpenAPI.
5. Mobile implementation.
6. Integration and release.

The backend-first choice does not remove the need to specify mobile UX and architecture in this foundation before coding begins.
